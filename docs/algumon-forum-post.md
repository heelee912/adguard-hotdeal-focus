# 핫딜 보러 갔다가 인기글로 새는 게 싫어서, 본문·댓글만 남기는 스크립트를 만들었습니다

알구몬에서 핫딜 하나 눌렀다가, 옆에 있는 인기글이나 추천글을 더 오래 보고 있었던 적 있으신가요?

상품 정보와 댓글만 읽고 돌아오고 싶어서 만든 유저스크립트입니다. 가격을 보러 갔다가 불필요한 논쟁글까지 읽고 오는 일을 좀 줄여 보자는 생각으로 만들었습니다.

## 이렇게 달라집니다

- 광고·사이드바·인기글·추천글·다른 글 목록을 숨깁니다.
- 가격·구매 링크·본문 사진과 영상·댓글·대댓글은 원래 페이지 그대로 남깁니다.
- 글 위쪽에 **알구몬으로 돌아가기 / 본문 / 댓글** 버튼이 생깁니다.
- 설치한 다음에는 평소처럼 핫딜 링크를 열면 됩니다. 같은 글을 직접 열어도 적용됩니다.

클리앙·뽐뿌·루리웹·퀘이사존·어미새·ZOD·아카라이브의 지원 핫딜 글에 적용됩니다. 사이트 전체를 바꾸는 것은 아니고, 일반 게시판이나 목록은 그대로입니다.

## 설치는 한 번만 하시면 됩니다

**Windows 또는 Android용 AdGuard 앱**에서 설치해 주세요. 브라우저용 AdGuard 확장 프로그램이나 필터 목록에 추가하는 방식은 아닙니다.

1. AdGuard 앱에서 아래 메뉴를 엽니다.
   - **Windows:** 확장 프로그램 → 확장 프로그램 추가 → 파일 또는 URL에서 가져오기
   - **Android:** 설정 → 필터링 → 확장 프로그램 → 확장 프로그램 추가 → 파일 또는 URL에서 가져오기
2. 아래 주소를 붙여넣어 설치하고 켭니다.
3. 이미 열려 있던 글은 새로고침합니다.

```text
https://heelee912.github.io/adguard-hotdeal-focus/hotdeal-focus.user.js
```

이 스크립트 하나만 있으면 됩니다. 이전 핫딜 전용 필터 목록을 쓰셨다면 해당 목록을 제거하고 스크립트만 사용해 주세요.

## 업데이트와 문제 제보

늦게 추가되거나 위치가 바뀐 요소도 다시 검사하고, 일부 페이지 구조 변경에는 자동으로 대응합니다. 수정된 새 버전은 AdGuard의 업데이트 설정에 따라 같은 주소에서 받습니다. 다만 사이트가 크게 바뀌면 추가 수정이 필요할 수 있습니다.

Windows의 실제 Chrome과 모바일 화면 폭으로 확인하고 있으며, Android 실기기 검증은 아직 하지 못했습니다. 내용이 잘리거나 불필요한 요소가 남는다면 **글 주소·사용 기기·브라우저**를 알려 주시면 확인에 도움이 됩니다.
